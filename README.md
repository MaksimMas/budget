# Копилка — общий бюджет

Сайт для учёта доходов и расходов вместе с семьёй. Работает с телефона и компьютера, данные лежат в вашей бесплатной базе Supabase.

В папке три файла:

| Файл | Зачем |
|---|---|
| `index.html` | Весь сайт целиком. Его нужно выложить в интернет. |
| `schema.sql` | Таблицы и правила доступа. Выполняется один раз в Supabase. |
| `README.md` | Эта инструкция. |

Чтобы просто посмотреть, откройте `index.html` двойным щелчком и нажмите «Открыть демо».

## Перед настройкой: проверьте доступность

Откройте без VPN с домашнего интернета и с мобильного:

- `https://supabase.com` — здесь будет база;
- `https://github.com` — здесь будет лежать сайт.

Если что-то из этого открывается плохо, сайт будет работать так же плохо. В этом случае `index.html` можно выложить на любой другой статический хостинг, а базу перенести на другой сервис: весь обмен с базой собран в одном классе `RemoteStore` внутри `index.html`.

## Шаг 1. База в Supabase (около 10 минут)

1. Зарегистрируйтесь на supabase.com и создайте проект (New project). Пароль базы сохраните, регион выберите ближайший.
2. Откройте **SQL Editor**, создайте новый запрос, вставьте содержимое `schema.sql` целиком и нажмите **Run**. Должно появиться «Success».
3. Откройте **Authentication → Sign In / Providers → Email** и выключите **Confirm email**. Так участники смогут входить сразу после регистрации. Если оставить включённым, каждому придёт письмо со ссылкой, а на бесплатном тарифе таких писем можно отправить всего несколько в час.
4. Откройте **Project Settings → API** (или **API Keys**) и скопируйте:
   - **Project URL** — вида `https://abcdefgh.supabase.co`;
   - **Publishable key** (`sb_publishable_…`) или, в старых проектах, **anon public** ключ.

Ключ `service_role` / `secret` никуда не вставляйте: он даёт полный доступ к базе.

## Шаг 2. Впишите адрес и ключ в сайт

Откройте `index.html` в Блокноте, найдите в начале скрипта блок `CONFIG` и заполните:

```js
const CONFIG = {
  supabaseUrl: 'https://abcdefgh.supabase.co',
  supabaseKey: 'sb_publishable_...',
};
```

Publishable/anon-ключ рассчитан на то, чтобы лежать в открытом коде: чужие данные по нему не прочитать, доступ ограничен правилами из `schema.sql`.

Если этот шаг пропустить, сайт спросит адрес и ключ при первом открытии на каждом устройстве.

## Шаг 3. Выложите сайт на GitHub Pages

1. На github.com создайте **публичный** репозиторий, например `budget`.
2. Нажмите **Add file → Upload files**, загрузите `index.html`, подтвердите (**Commit changes**).
3. Откройте **Settings → Pages**, в разделе Build and deployment выберите **Deploy from a branch**, ветку **main**, папку **/(root)**, нажмите **Save**.
4. Через минуту-две сайт откроется по адресу `https://ВАШ_ЛОГИН.github.io/budget/`.

Чтобы обновить сайт, загрузите новый `index.html` поверх старого тем же способом.

## Шаг 4. Начало работы

1. Откройте адрес сайта, зарегистрируйтесь, создайте бюджет.
2. На телефоне откройте тот же адрес и войдите с той же почтой и паролем.
3. Добавьте сайт на главный экран: в Safari «Поделиться → На экран Домой», в Chrome «⋮ → Добавить на главный экран». Он будет открываться как приложение.

## Совместный учёт

- **Участники → Пригласить** создаёт ссылку и код. Приглашение действует 7 дней.
- Приглашённый открывает ссылку, регистрируется и попадает в ваш бюджет.
- Роли: **владелец** управляет участниками и бюджетом, **редактор** ведёт операции и категории, **наблюдатель** только смотрит.
- Чужие операции появляются при открытии сайта и обновляются примерно раз в 45 секунд.
- У одного аккаунта может быть несколько бюджетов (личный, семейный, на отпуск), они переключаются в списке сверху.

## Операции из СберБанка (Android)

Прямого подключения к Сберу для частных лиц нет, поэтому сайт принимает тексты уведомлений с телефона.

1. Выполните в Supabase актуальный `schema.sql` (если база создана раньше, просто запустите файл ещё раз: он ничего не удаляет).
2. На сайте откройте **Входящие → Подключить телефон**. Там показаны адрес, заголовок `apikey` и ваш личный токен.
3. Установите на телефон приложение-автоматизатор, например MacroDroid, и создайте макрос:
   - триггер: получено уведомление от приложения СберБанк;
   - действие: HTTP-запрос, метод `POST`, тип содержимого `text/plain`, заголовок `apikey` со значением с сайта;
   - тело запроса: первая строка — токен, вторая — переменная «заголовок уведомления», третья — переменная «текст уведомления» (вставляются кнопкой переменных в приложении).
4. Разрешите приложению доступ к уведомлениям и отключите для него экономию батареи, иначе Android будет его усыплять.
5. В приложении СберБанк включите пуш-уведомления об операциях.

Дальше покупки появляются во «Входящих». Для нового магазина один раз выбираете категорию, сайт её запоминает, и следующие операции из этого магазина добавляются одной кнопкой. Коды входа и рекламу сайт помечает как «не похоже на операцию».

Если запрос с телефона возвращает ошибку 404 или 415, используйте запасной вариант: адрес `…/rest/v1/rpc/ingest`, тип `application/json`, тело `{"p_token":"ТОКЕН","p_title":"…","p_body":"…"}`. Он ломается, если в тексте уведомления встретятся кавычки, поэтому основной вариант надёжнее.

Уведомления видит только владелец телефона. Остальные участники видят уже добавленные операции.

## Настройка под себя

В самом сайте, раздел «Настройки»: тема, акцентный цвет, копейки, блоки на «Обзоре», название и валюта бюджета. В «Категориях»: значки, цвета, порядок, месячные лимиты, архив.

В коде `index.html`:

- блок `:root` в начале — все цвета, скругления, шрифт;
- `DEFAULT_CATEGORIES` — набор категорий для нового бюджета;
- `EMOJIS`, `ACCENTS`, `CURRENCIES` — значки, цвета и валюты на выбор.

## Что стоит знать

- На бесплатном тарифе Supabase ставит проект на паузу, если к нему долго никто не обращался. Проект включается обратно кнопкой в панели Supabase, данные сохраняются.
- Резервную копию можно скачать в «Настройки → Резервная копия (JSON)».
- Забытый пароль сейчас сбрасывается только из панели Supabase: **Authentication → Users**.
